# 参考标注说明 v3:论断是否被论文支持(对照全文)

和 v2 的区别只有一处:**依据是整篇论文**,不只是摘要。全文已解析成带编号的段落,存在 `eval/.fulltext_cache/<arXiv id>.json`(`paragraphs` 里每条有 `p` 段落编号、`s` 章节、`text`)。没有 HTML 的论文只有摘要(`status: abstract_only`),那就只看摘要。

**标注时不要打开任何评判结果**:`*.judge.json`、`*.v2.json`、`*.v3.json`、`runs/**/claim_judgments*.json`。

## 每一行怎么做

1. 读 `claim`(综述里的一句话)和 `key` 最后一段的 arXiv 编号(这一行要判的论文)。
2. 在该论文的全文里找与这句话相关的段落(按关键词、数字、方法名搜),读够再判断。先看摘要,再看实验/结果/结论。
3. 在 `human_label` 填一个标签,`note` 写依据的段落编号(如 `S4.p2`)或一句理由。

## 标签

| 标签 | 什么时候用 |
|---|---|
| `supported` | 论文(任何位置)明确说了,或能直接推出,这句话归到这篇论文身上的内容 |
| `partial` | 主要意思成立,但有一部分论文里没有(多加的细节、推断出的局限、说过头),或某个数字、细节和论文不一致 |
| `unsupported` | 这句话归到这篇论文身上的内容,论文里都找不到;尤其是论文讲的是另一个方法或主题(引错了论文) |
| `contradicted` | 论文讲的正是这件事,并且明确说了相反的结论;数字不对、论文没提、引错论文都**不算** contradicted |

## 和 v2 相同的规则

- 先看论文是不是在讲这句话描述的工作。完全是另一回事,就是引错论文:标 `unsupported`。
- 一句话引了好几篇:只判和**这一篇**有关的部分。其他论文的部分、综述作者自己的概括("学界已有共识""仍未解决")不算,除非句子说这是这篇论文自己的观点。
- 作者名和年份只是引用标记,不用核对。
- 对这篇论文的批评("没有处理 X""只限于 Y")也是关于它的陈述,要核对。
- 论文没写、由综述推出的局限或后果("可能无法推广到……"):其余都成立时标 `partial`。
